# 音频检测与定位模型对接要求

系统提供整段音频真假检测和伪造片段时间定位。模型提供方负责选择并交付可运行的模型；后端开发负责上传、任务调度和统一输出；前端开发负责播放、整段判断和时间轴标红。建议优先接入一个定位模型，再补充整段检测对照模型。

## 候选模型

| 候选 | 适用角色 | 官方资源与接入注意 |
| --- | --- | --- |
| PartialSpoof 多分辨率模型 | 优先验证整段检测及定位 | [官方推理说明](https://github.com/nii-yamagishilab/PartialSpoof/blob/main/03multireso/README.md) 提供预训练下载脚本和整段、分段输出；选定输出尺度后明确帧到秒映射，加载单个确定版本的权重 |
| BAM | 定位候选 | [作者仓库](https://github.com/media-sec-lab/BAM) 给出定位代码与 checkpoint 链接；需把基准评测入口改成不依赖测试真值的单音频推理，整体分数如何产生要另外声明 |
| AASIST 或 AASIST-L | 整段检测对照 | [官方仓库](https://github.com/clovaai/aasist) 提供预训练模型；在本草案中按仅整段分类接入，分类输出不得作为时间定位结果 |

上述模型为接入候选，尚未下载或运行。官方资源声明提供权重，但权重下载可用性及本机环境兼容性尚待验证。最终选型依据包括单文件推理可用性、定位输出、依赖、中文样例表现和实际设备耗时。

## 统一模型入口

以下定义统一模型接口；配套实现位于 `backend/voxguard/adapters.py`，配置式 PyTorch 接入及检查命令见 [模型接入目录](../model_integration/README.md)：

```python
describe() -> ModelDescriptor
predict(audio: AudioInput, mode: str, include_timeline: bool) -> Prediction
```

`describe()` 的公开信息映射到 `GET /api/v1/models`；`predict()` 的输出映射到 HTTP 结果的 `result`。同一进程函数、独立进程或后续模型服务均可实现，前端不直接调用这个入口。

输入 `AudioInput`：

| 字段 | 要求 |
| --- | --- |
| `waveform` | 已解码 CPU float32，形状 `[channels, samples]`，全部有限值 |
| `sample_rate_hz` | 原始解码采样率，不提前强制改成 16 kHz |
| `duration_sec` | 原始解码有效样本数除以采样率；作为输出时间轴依据 |
| `audio_id` | 后端内部标识，仅用于记录与排错 |

整型 PCM 按位深转换至浮点的约定须固定；通常落在 `[-1,1]`，有损解码可能略有超出，不静默削波或进行逐条峰值归一化。异常值拒绝处理；模型需要的幅度归一化由适配器记录在预处理版本中。样例真值、伪造区间及真实标签均不传入 `predict()`。

适配器负责声道处理、采样数据重采样、特征提取、切块和补齐。推荐优先考察支持 16 kHz 单声道的模型以简化接入，但实际采样率以模型声明为准。不得仅截取音频开头后返回全段已检测；不支持的时长返回错误。

默认保留静音及原始时间原点。若内部 VAD、裁剪或拼接改变时间，必须维护回到原始音频的映射。尾部 padding 不计入时长和定位。窗口重叠区的融合权重、窗口边界处理、最后不足一窗的策略都要固定。

## 必须返回的结果

1. `decision`：标签、整段伪造分数、整段阈值。适配器统一为分数越高越倾向于伪造，并明确原始正负类别及转换公式。数值不要求在 0～1；未经校准的分数不得称为概率。
2. `localization`：定位状态、原始时间轴上的伪造区间、有效时间粒度、定位阈值和后处理版本。在 `detect` 模式，无定位能力用 `unsupported`，有能力但本次未请求用 `not_requested`；完成定位但未检出用 `available` 加空数组。
3. `timeline`：请求时返回连续、不重叠的秒级时间格及分数。模型原生输出可以是帧数组或窗口，但适配器必须补齐明确的时间对应关系。

首版定位适配器需要能取得逐帧或窗口分数及其时间映射，用于生成一致的区间分数和可选时间序列。`include_timeline=false` 仅省略序列传输。只有无分数起止区间的模型暂不符合本版定位契约，不得人工构造帧分数以补足输出。

所有数值有限，区间合法且不超出音频。只有 `detect_and_localize` 模式要求检测与定位共同成功，否则抛出约定错误，由后端置任务为 `failed`；`detect` 模式只执行整段检测。不能以零分或空数组隐藏失败。

如果只有定位头，可以用预先确定的聚合规则产生整段分数，但必须在随权重交付的模型说明中注明 `derived`、公式和单独的验证阈值；该说明绑定模型版本，不新增前端字段。简单取最大值可能受音频长度影响，不能未经验证就声称等价于原生整段检测头。若仅有整段分类，不允许复制分数或扫描分类器输出后宣称具备已验证的精确定位能力。

## 帧到片段的规则

模型提供方需说明原生帧窗长、步长、第一帧偏移、感受野及标签时间含义。适配器将重叠预测融合为覆盖整个有效音频的时间格，所有融合和平滑规则纳入版本。

用于第一轮联调的建议后处理为：在固定粒度上用 `>= localization_threshold` 标记可疑格；合并连续可疑格；如有间隔合并或最短片段过滤，提供其秒数及验证依据。缺少依据时采用合并间隔 0、最短片段过滤 0，避免过滤缺少验证依据的短伪造片段。片段分数为最终区间内、包括被合并间隙的时间加权均值。

输出 `resolution_sec` 按实际使用的有效粒度填写，不用插值后的绘图步长替代。阈值从独立开发集选取并冻结；若只有演示值，要在模型说明中明确，不能在测试集调阈值后再用该集报告效果。

## 模型交付清单

| 项目 | 需要的信息或文件 |
| --- | --- |
| 身份 | 模型名、源码地址、代码提交版本、配置、权重文件及 SHA-256 |
| 能力 | 整段检测、定位分别支持与否；整段分数是原生还是派生 |
| 输入 | 采样率、声道、幅度处理、最短/最长时长、切块与 padding 策略 |
| 输出 | 原始标签映射、分数方向与范围、帧时间映射、完整输出示例 |
| 阈值 | 检测阈值、定位阈值、来源开发集、是否仅用于演示 |
| 后处理 | 重叠融合、平滑、合并间隔、最短片段、分数聚合方式和版本 |
| 环境 | Python/PyTorch 等准确依赖、CPU/GPU 支持、所需额外预训练组件 |
| 资源 | 在具体设备上，5 秒及 30 秒音频的实际推理耗时、峰值内存/显存；无实测则填待测 |
| 样例 | 数据准备方提供音频及标签；模型提供方至少返回一条局部伪造样例的实际推理输出，建议补充真实、整段伪造、局部伪造各一条参考输出 |
| 使用条件 | 代码、权重、基础模型、数据各自许可及引用要求，不能以代码许可覆盖全部 |

对外 `model.version` 必须唯一绑定权重、预处理、阈值和后处理；其中任一项变化即产生新版本。后端受理任务时固定版本，后续切换默认模型不能改变历史任务的解释。

## 接入完成的判据

在固定权重和依赖下，可以对一条无真值输入的音频独立运行推理，返回约定格式；帧和片段能对齐播放器的原始秒数；异常输入有明确错误；可复现模型提供方的参考输出（允许事先说明的浮点容差）。当前 30 条交付样例用于联调和问题排查，不足以证明模型达到特定准确率。
