# VoxGuard 前端工程

本目录为原生 HTML、CSS 和 JavaScript 前端，保留上传区、检测结果、波形、片段列表、历史记录和接口设置页面。应用通过 HTTP 调用后端，不在浏览器中生成检测结论。

## 启动与使用

按工程根目录 `README.md` 启动后端后，打开其首页。后端同时提供本目录静态文件和 `/api/v1`，无需单独安装 Node.js 或构建前端。不要直接以 `file://` 打开 `index.html`。

1. 等待模型目录加载，选择就绪模型及分析范围。只有支持定位的模型可选择“真假检测＋时间片段定位”。
2. 上传一个符合页面限制的 WAV、FLAC 或 MP3。限制来自服务和所选模型的交集。
3. 点击“开始检测”，等待任务完成。完成后加载服务端 WAV 预览，显示后端判断、模型分数、阈值和定位片段。
4. 点击片段试听，或导出包含任务 ID、模型版本、模拟标识、原始结果和警告的 JSON 报告。

“载入测试音”仅生成 24 秒非语音测试信号，不自动提交，也不生成分数。默认可用的模拟联调模型必须通过真实 HTTP 任务流程调用；其结果不代表模型推理或检测能力。

## 接口行为

- 默认 API 基础地址为 `/api/v1`。分别部署时，在接口设置中填写完整后端基础地址，后端需允许实际前端来源；请求不携带登录凭据。
- `GET /models` 读取模型、版本、`is_mock`、能力和限制。`unavailable` 模型不可选择；目录为空或连接失败时禁用检测，可点击“重新连接”。
- `POST /analyses` 上传 `file`、`model_id`、`mode`、`include_timeline=false`。上传不会自动重试。
- 每秒查询 `GET /analyses/{analysis_id}`；遇到 `429/503` 根据 `Retry-After` 最多重试三次，无该头时退避至最多 5 秒。服务要求等待超过 30 秒时停止本次查询并提示稍后重试；不提前重试该请求。
- 成功后完整下载 WAV 预览为 Blob。预览地址解析到配置的后端来源，时间轴使用响应中的 `audio.duration_sec`。预览加载失败不影响已经取得的结果和报告导出。
- “停止等待”只中止浏览器上传或查询等待，不发送服务端取消请求，不表示服务端任务已取消。上传超时或中断可能已创建任务，页面不自动重复提交。

分数可为任意有限实数，包括负数和大于 1 的值。显示值仅为排版进行有效数字格式化，导出的原始值不变；不转换为百分比、不用本地阈值覆盖后端判断。圆环只表示结果已返回，不表达概率或分数占比。

定位区间按服务端边界直接展示，不重新合并、不取最大值替换片段分数。分别展示 `available + []`、`unsupported` 和 `not_requested`。模拟标识以任务响应的 `is_mock` 为准。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html`、`styles.css`、`favicon.svg` | 页面结构、样式和图标 |
| `app.js` | 文件选择、播放器、任务状态、结果展示、历史与导出 |
| `analysis.js` | 输入检查、接口结构检查、结果映射、时间与分数格式化、测试音生成 |
| `api.js` | 上传、任务查询、GET 重试、超时和停止等待 |
| `tests/*.test.js` | 分数与定位语义、模型来源、输入限制及请求状态机测试 |
| `package.json` | 可选 Node.js 测试入口，页面运行不依赖 npm 包 |

历史使用新的 `voxguard:v2:*` 浏览器存储键，不将旧版百分比分数历史混入当前结果。只保存最近 30 条完整成功结果，不持久保存音频。历史页仅导出报告，不把旧记录关联到当前文件播放。

## 检查

如需运行前端逻辑测试，安装 Node.js 20 或更高版本，在本目录执行：

```sh
npm test
```

无 npm 依赖，不需要 `npm install`。接口字段以工程根目录 `contracts/openapi.yaml` 为准；浏览器联调验证记录见根目录交付说明。
